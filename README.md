# PRODIGY_SD_03 – Contact Management System

## About
A simple Contact Management System developed using Python as Task 03 of the Prodigy InfoTech Software Development Internship.

## Features
- Add new contacts
- View all saved contacts
- Edit existing contacts
- Delete contacts
- Exit the program

## Technologies Used
- Python
- Dictionary
- Conditional Statements
- Loops

## How to Run
1. Download the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python contact_management.py
```
